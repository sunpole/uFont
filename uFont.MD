# Проект: Каталог кириллических шрифтов (аналог Google Fonts, но удобнее)

Хочу разработать собственный каталог кириллических шрифтов, основанный на Google Fonts, но с более мощной системой поиска и сравнения начертаний.

## Главная идея

Это **не просто список шрифтов**, а инструмент для дизайнеров.

Основная задача — максимально быстро сравнивать одинаковые начертания разных семейств.

Например:

* все Bold
* все Black
* все Italic
* все Condensed

одновременно.

Google Fonts такого не умеет.

---

# Источник данных

Основной источник:

Google Fonts

Нужно получить **все семейства, поддерживающие кириллицу**.

Не парсить HTML сайта.

Использовать внутренний JSON/API или официальный каталог Google Fonts.

---

# Что хранится для каждого семейства

```json
{
    "family": "Roboto",
    "designer": "Christian Robertson",
    "category": "sans-serif",
    "variable": true,

    "subsets":[
        "latin",
        "cyrillic",
        "greek"
    ],

    "styles":[
        "Thin",
        "Thin Italic",
        "Light",
        "Light Italic",
        "Regular",
        "Italic",
        "Medium",
        "Medium Italic",
        "SemiBold",
        "SemiBold Italic",
        "Bold",
        "Bold Italic",
        "ExtraBold",
        "ExtraBold Italic",
        "Black",
        "Black Italic"
    ],

    "tags":[
        "sans",
        "ui",
        "modern",
        "minimal",
        "google",
        "web"
    ]
}
```

Отдельная таблица.

Например

# Главное отличие от Google Fonts

Каждое начертание отображается отдельной карточкой.

Не переключается.

Показывается сразу.

Например

```
Roboto

Regular

400 г. МАССА.



Italic

400 г. МАССА.



Bold

400 г. МАССА.



Black

400 г. МАССА.
```

Все карточки располагаются **горизонтально в одной строке**.

---

# Глобальные фильтры

Сверху находятся чекбоксы.

Например

```
☑ Thin

☑ Light

☑ Regular

☑ Italic

☑ Medium

☑ SemiBold

☑ Bold

☑ ExtraBold

☑ Black

☑ Condensed

☑ Expanded
```

Если отключить

```
Regular
Italic
Medium
```

то исчезают соответствующие столбцы сразу у всех шрифтов.

Остаются только

```
Bold

Black

Condensed
```

Таким образом можно анализировать, например, только Bold всех кириллических шрифтов.

# Табличный режим

Именно такой режим нужен.

```
Название          Regular   Italic   Bold   Black   Condensed

Roboto            ███████   ██████   █████  ███████    —

Inter             ███████      —      █████     —      —

Roboto Condensed  ███████   ██████   █████     —     ███████

Playfair          ███████   ██████   █████  ███████    —
```

Каждая ячейка —

не текст,

а реальное превью шрифта соответствующего начертания.

# Цель

Получить каталог, который **удобнее Google Fonts именно для подбора и сравнения шрифтов**.

Основная фишка проекта — возможность одним взглядом сравнить одинаковые начертания (Bold, Black, Italic, Condensed и т.д.) у сотен кириллических семейств, чего сейчас не предоставляет Google Fonts.

## Что я бы предложил добавить в следующей итерации

Есть ещё одна идея, которая, как мне кажется, сделает каталог ещё сильнее. Добавить **несколько режимов отображения**, а не один:

1. **Таблица** — как мы придумали (для сравнения начертаний между семействами).
2. **Галерея** — по одной большой карточке на семейство, как в Google Fonts.
3. **Матрица** — семейства по вертикали, стили по горизонтали (для профессионального сравнения).
4. **Лупа** — при наведении на любую ячейку показывать увеличенное превью с дополнительными строками текста и цифр.

Тогда каталог будет полезен и для быстрого поиска, и для детального анализа шрифтов.
