# uFont — общая база пользовательских тегов

Пользовательские теги хранятся в `data/user-tags.json`. Файл находится в GitHub и поэтому одинаково читается на GitHub Pages, телефоне и других компьютерах.

## Добавление, изменение и удаление тегов

1. Получите последнюю версию: `git pull --ff-only`.
2. Запустите локальный сервер: `npm start`.
3. Откройте `http://localhost:4173`.
4. Нажмите `＋ тег` возле семейства и укажите теги через запятую. Пустое поле удаляет все пользовательские теги семейства.
5. Остановите сервер сочетанием `Ctrl+C`.
6. Опубликуйте базу: `npm run publish:tags`.

GitHub Pages обновится автоматически. На самом GitHub Pages теги доступны только для чтения: это защищает репозиторий и не требует хранения GitHub-токена в браузере.

## Condensed / Narrow / Compressed

Фильтр определяет узкие семейства по названию, Google-тегам и variable-оси `wdth`. Также доступна сортировка «Condensed сначала».
