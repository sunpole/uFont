# uFont — общая база пользовательских тегов

Пользовательские теги хранятся в `data/user-tags.json`. Файл находится в GitHub и поэтому одинаково читается на GitHub Pages, телефоне и других компьютерах.

## Добавление, изменение и удаление тегов

1. Получите последнюю версию: `git pull --ff-only`.
2. Запустите локальный сервер: `npm start`.
3. Откройте `http://localhost:4173`.
4. Нажмите `＋ тег` возле семейства и укажите теги через запятую. Пустое поле удаляет все пользовательские теги семейства.
5. Остановите сервер сочетанием `Ctrl+C`.
6. Опубликуйте базу: `npm run publish:tags`.

GitHub Pages обновится автоматически. На самом GitHub Pages изменения остаются локальным черновиком до экспорта JSON: это защищает репозиторий и не требует хранения GitHub-токена в браузере.

## Работа со статической версией и перенос тегов

На GitHub Pages можно создавать черновые пользовательские теги. Они временно сохраняются в браузере устройства.

1. Создайте теги кнопкой `＋ тег`.
2. Нажмите `Экспорт JSON` и сохраните файл.
3. Перенесите JSON на рабочий компьютер.
4. Запустите локальный проект через `npm start`.
5. Нажмите `Импорт JSON` и выберите сохранённый файл.
6. Выполните `npm run publish:tags`.

Импорт объединяет новые данные с `data/user-tags.json`. Названия семейств приводятся к каноническому написанию, теги — к нижнему регистру; лишние пробелы и дубли удаляются автоматически.

## Condensed / Narrow / Compressed

Фильтр определяет узкие семейства по названию, Google-тегам и variable-оси `wdth`. Также доступна сортировка «Condensed сначала».
