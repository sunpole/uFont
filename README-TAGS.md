# uFont — общая база пользовательских тегов

Пользовательские теги хранятся в `data/user-tags.json`. Файл находится в GitHub и поэтому одинаково читается на GitHub Pages, телефоне и других компьютерах.

Режим **Теги** открывает центральную страницу управления. На ней можно создавать, переименовывать и удалять теги, менять их цвета или полностью очистить пользовательскую базу.

Одному семейству можно назначить до **99 тегов**. В окне `＋ тег` перечисляйте их через запятую; одинаковые значения автоматически объединяются без дублей.

Цвета и переносимый профиль хранятся вместе с назначениями в `data/user-tags.json` (схема 3):

```json
{
  "schemaVersion": 3,
  "families": {
    "Roboto": ["рабочий", "интерфейс"]
  },
  "tagMeta": {
    "рабочий": { "color": "#205f46" }
  },
  "preferences": {
    "favorites": ["Roboto"],
    "rareFonts": [],
    "invertTagFilter": false,
    "tagScale": 100
  }
}
```

Локально изменения сразу записываются сервером `npm start`. На GitHub Pages они сохраняются черновиком в браузере; используйте **Экспорт JSON**, перенесите файл на рабочий ПК, выполните **Импорт JSON**, а затем `npm run publish:tags` из ветки `main`.

Фильтр **Инверсия** показывает семейства, которые не удовлетворяют выбранному набору тегов. Масштаб списка тегов регулируется от 50% до 200% и примагничивается к 100%.

## Что переносится между устройствами

- пользовательские теги и их цвета;
- избранные и редкие шрифты;
- выбранные и инверсные теги;
- сортировка и масштаб тегов;
- столбцы и фильтры каталога;
- размер текста, PPI и режим отображения;
- шрифты, координаты, масштаб, прозрачность, цвет и наложение инспектора.

Локальное изображение инспектора не включается в JSON: браузер не должен загружать личные изображения в публичный репозиторий. Его нужно выбрать заново на каждом устройстве.

## Добавление, изменение и публикация

1. Получите последнюю версию: `git pull --ff-only`.
2. Запустите локальный сервер: `npm start`.
3. Откройте `http://localhost:4173`.
4. Используйте `＋ тег` возле семейства или страницу **Теги**.
5. Остановите сервер сочетанием `Ctrl+C`.
6. Опубликуйте базу: `npm run publish:tags`.

GitHub Pages обновится автоматически. На самом GitHub Pages изменения остаются локальным черновиком до экспорта JSON: это защищает репозиторий и не требует хранения GitHub-токена в браузере.

Импорт объединяет данные с текущей базой. Названия семейств приводятся к каноническому написанию, теги — к нижнему регистру; лишние пробелы и дубли удаляются автоматически.
